## Security Awareness Studio 0.2.0

Characters in four styles, and the speaker now talks and blinks.

### Start here

```bash
git clone https://github.com/xIBBAx/security-awareness-studio
cd security-awareness-studio
python3 -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install .
sastudio init my-film
sastudio characters my-film --sheet cast.png       # see the cast in all four styles
sastudio render my-film --preset draft
```

Then pick a style in `my-film/studio.yaml`:

```yaml
render:
  character_style: v3     # v1 sketch, v2 flat, v3 cutout, v4 clay (default)
```

No GPU, no account and no API key are needed. This version is not on PyPI: install from the
repository as above.

### New

- **Four character styles.** v1 sketch, v2 flat and v3 cut-out are drawn by this tool from scratch
  at render time; v4 is the bundled clay portraits. Choose one for the film and override it for
  any character.
- **The speaker talks and blinks** in the drawn styles: the mouth follows the voice, or the letters
  of the subtitle when the voice is the silent placeholder. Bodies stay still; cards still cut.
- **Describe your own characters in text** (`look.design`): skin, ten hair styles including a
  headscarf, six outfits including a kurta, shoes, glasses, beard, bindi, earrings and more.
- **A final film refuses a placeholder reporting address**, so `security@example.com` can't reach
  an organisation by mistake.

### Known limitations

- Clay (v4) characters are still portraits; the clay renderer's engine is not included.
- Only the face moves in the drawn styles: no gestures, walking or lip shapes per sound.
- The Sarvam and ElevenLabs adapters were tested against recorded responses only.
- Offline placeholder voices are silent unless espeak-ng is installed.

### Reference media

| File | What it is |
|---|---|
| `Security_Awareness_in_Twelve_Stories.en-IN.mp4` | the 12-scene starter film in the cut-out style, 1920x1080, with `.srt`, `.vtt`, transcript and manifest |
| `Security_Awareness_Trailer.v1-sketch.en-IN.mp4` ... `.v4-clay.en-IN.mp4` | the same five scenes in each of the four styles, 1920x1080; one `.srt` and `.vtt` |
| `Example_Quillmere_Security_Essentials.en-IN.mp4`, `.hi-IN.mp4` | the worked example in English and Hindi, cut-out style, 960x540 |
| `MEDIA_SHA256SUMS` | checksums of the files above |
| `SHA256SUMS` | checksums of the wheel and source archive |

The voices in these films are the offline placeholder, which is silent: the dialogue is in the
on-screen text and the subtitles. They were made from this repository alone
(`tools/make_reference_media.py`); how they were checked is in `docs/media/film/VERIFY.md`.

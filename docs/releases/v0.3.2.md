## Clayvoyant 0.3.2

Clayvoyant is on PyPI:

```bash
pip install clayvoyant
```

This release only changes how the package presents itself there: the README's pictures and links
work on the PyPI page, and the changelog link points to `docs/CHANGELOG.md`. The code is the same
as 0.3.1, and the films stay on the [0.3.1 release](https://github.com/xIBBAx/clayvoyant/releases/tag/v0.3.1).

### Files

- The wheel, the source archive and `SHA256SUMS`, built from the tag by the release workflow.

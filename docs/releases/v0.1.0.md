## Security Awareness Studio 0.1.0

The first public version: a command-line tool that builds captioned security-awareness training
films from a folder of plain text files, with your organisation's name, colours, logo, reporting
address, characters, languages and voices.

### Start here

```bash
git clone https://github.com/xIBBAx/security-awareness-studio
cd security-awareness-studio
python3 -m venv .venv && . .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install .
sastudio init my-film
sastudio render my-film --preset draft
```

You need Python 3.11+ and FFmpeg ([installation guide](https://github.com/xIBBAx/security-awareness-studio/blob/main/docs/INSTALLATION.md)).

No GPU, no account and no API key are needed. Real voices from Sarvam or ElevenLabs use your
own account and only run with `--live` and a character budget.

This version is not on PyPI: install from the repository as above. (A package called
`security-awareness-studio` on PyPI is not from this project until a release note here says so.)

### What it makes

Cards films: a still portrait of whoever is speaking, every line in large on-screen text, key-point
cards and hard cuts, with SRT and WebVTT subtitles, a transcript and a checksummed manifest. The
characters are not animated in this version.

### In this release

- 12-scene starter project (English), a 3-scene English and Hindi template, an education template,
  and a 3-scene worked example in English and Hindi (`examples/quillmere`).
- Cards renderer: 960x540, 1280x720 or 1920x1080 at 24 fps, H.264/AAC, with SRT and WebVTT
  subtitles, a transcript and a checksummed manifest. Only changed scenes are rendered again.
- Voices: Sarvam, ElevenLabs and a free offline provider, with a content-addressed cache, budgets
  and a request ledger.

### Known limitations

- The clay renderer's engine is not included; the five characters ship as still portraits.
- If a character uses Sarvam or ElevenLabs, `render` stops until those lines are generated; add
  `--voice-fallback offline` to preview with labelled placeholder voices.
- The Sarvam and ElevenLabs adapters were tested against recorded responses only. No live
  request was made for this release. Try a provider on one scene with a small budget first.
- Offline placeholder voices are silent unless espeak-ng is installed.
- Windows is covered by CI; Windows desktop use outside CI and macOS have not been tested by the
  maintainer.

### Reference media

| File | What it is |
|---|---|
| `Security_Awareness_in_Twelve_Stories.en-IN.mp4` | the 12-scene starter film, 1920x1080, about 14 minutes, with `.srt`, `.vtt`, transcript and manifest |
| `Security_Awareness_Trailer.en-IN.mp4` | five scenes from it, 1920x1080, with `.srt` and `.vtt` |
| `Example_Quillmere_Security_Essentials.en-IN.mp4`, `.hi-IN.mp4` | the worked example in English and Hindi, 960x540, with subtitles |
| `MEDIA_SHA256SUMS` | checksums of the files above |
| `SHA256SUMS` | checksums of the wheel and source archive |

The voices in these films are the offline placeholder, which is silent: the dialogue is in the
on-screen text and the subtitles. They were made with this release from the files in this
repository alone (`tools/make_reference_media.py`); how they were checked is in
`docs/media/film/VERIFY.md`.
